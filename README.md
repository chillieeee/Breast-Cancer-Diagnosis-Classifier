# Breast-Cancer-Diagnosis-Classifier

This repository contains a machine learning project for Breast Cancer Diagnosis.
It features an exploratory analysis script, a Random Forest Classifier trained on the Wisconsin Breast Cancer dataset, and a Flask web application with a responsive user interface to serve model predictions.

## Features
- Exploratory data analysis of breast cancer metrics.
- Random Forest model for accurate malignant/benign classification.
- Flask backend with a beautiful frontend to input features and get real-time predictions.
